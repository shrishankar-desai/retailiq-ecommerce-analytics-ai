THE WORK BEHIND THE WORKSPACE

About & data

A self-directed analytics and recommendation engineering demonstration.

What RetailIQ does

RetailIQ turns historical shopping events into product and shopper analysis, then ranks unseen products using implicit-feedback recommendations.

Analytics pipeline

Event quality checks, UTC normalization, distinct visitor counts, item-level purchases, distinct order IDs and category history matched at event time.

Recommendation engine

Weighted item-to-item similarity, category-aware ranking and a popularity fallback, evaluated using chronological training, validation and test periods.

Implementation

Python, pandas, sparse matrices, FastAPI and Plotly. Reproducible processing, API tests, downloadable tables and Docker packaging are included in the repository.

Scope & limitations

Historical offline results do not establish revenue, ROI or sales uplift. Product names, prices and currency amounts are unavailable.
